# MUN Apartment — Official Website

Static bilingual website prepared for GitHub Pages.

## Repository

- Name: `munapartment`
- Description: `Official website of MUN Apartment`
- Visibility: Public
- GitHub Pages: `main` branch, `/ (root)`

## Publish

1. Create the GitHub repository `munapartment`.
2. Upload every file and folder while preserving the structure.
3. Open `Settings → Pages`.
4. Select `Deploy from a branch`.
5. Select `main` and `/ (root)`.
6. Save and wait for publication.

Expected address:

`https://<github-username>.github.io/munapartment/`
